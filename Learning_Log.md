# 📚 LEARNING LOG

## 🎯 Project Overview

**Learning Log** is a web application that allows users to log the topics they're interested in and make journal entries as they learn about each topic.

---

## 🏠 Home Page

The **Learning Log home page** will:
- Describe the site
- Invite users to either **register** or **log in**

---

## 👤 User Features

Once logged in, a user can:

### ✍️ Create New Topics
Start tracking new subjects you want to learn about

### 📝 Add New Entries
Write journal entries about your learning progress

### 📖 Read Existing Entries
Review what you've learned so far

### ✏️ Edit Existing Entries
Update and refine your learning notes

---

## 🔐 Authentication

- **Register** - Create a new account
- **Login** - Access your personal learning journal
- **Logout** - Securely sign out

---

## 💡 Key Concepts

**Learning Log** helps you:
- 📌 Organize your learning journey
- 📈 Track your progress over time
- 🎓 Build a personal knowledge base
- 🔍 Reflect on what you've learned
